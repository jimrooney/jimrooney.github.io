STAR 5000 INTERACTIVE FAMILIARIZATION TRAINER

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. No web server or internet connection is required.

WHAT IT IS
This is a procedural learning mock-up built from the visible installed panel layout
and publicly available general information about the STAR 5000.

It includes:
- Clickable front-panel controls
- Simulated navigation, position, message and flight-plan pages
- A Direct-To airport-selection exercise
- Flight-plan waypoint review
- Live groundspeed and 3-degree descent-rate calculation
- Five guided exercises
- An event log
- The user-provided installed-unit photograph as a reference

IMPORTANT LIMITATION
This is not a software-accurate emulator. The original pilot guide has not been located
and verified, so some screen formats and button behavior are deliberately simplified.
Do not use it as an operating reference. Confirm all real-world operation against the
actual unit, aircraft flight manual supplement, placards and approved documentation.
